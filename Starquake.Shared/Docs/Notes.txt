Notes for Starquake
===================

Remake and graphics (c) 2026 Damien Green. Original (c) 1985 Steve Crow

http://www.zxsoftware.co.uk/Data/Spectrum/S/instructions/Starquake.txt

The teleport codes have been changed for the remake so any you find on cheat sites won't give you any joy - sorry!

Speed
=====
The game runs at the original's speed: fifty logic frames a second, the UK PAL rate Starquake was written for.
It does that on any monitor. Drawing and game logic are separate - the picture is drawn once per vertical retrace,
so it stays smooth at whatever the display runs at, while the logic is stepped from a clock of its own at exactly
fifty frames a second. A 60Hz panel, a 144Hz one or an odd 59 makes no difference to how fast Blob moves.

This used to be a problem. The game was tied to the monitor's refresh, so it ran about 20% fast on the 60Hz
displays nearly everything now defaults to, and the note here said the only fix would be to redraw every graphic
so Blob moved in 6 steps instead of 8 - far too much work to contemplate. That turned out not to be the fix at
all. Separating the two clocks solved it without touching a single graphic, and Blob still moves in 8 steps.

Controls
========
- Move Blob with the cursor keys.
- Fire with Left Alt. (The authentic key was Ctrl, but on macOS Ctrl with an arrow key is taken by Mission
  Control and App Expose before the game ever sees it, which made firing while moving impossible.)
- Push up, while not moving left or right, to swap what Blob is carrying with whatever is on the floor.
- P pauses and unpauses. Q quits to the title screen.
- ESC exits to the desktop, as does Back on a gamepad.

Those are the defaults. The options screen at the start offers a joypad, the cursor keys, the original Spectrum
layout of O, P, A, Q and Space, and a scheme you define yourself key by key - and that screen is also where the
pause and quit keys come from, so they change with the scheme.

Function keys
=============
These are live whatever the control scheme:

- F8 switches the artwork between the redrawn graphics and the original 1985 set. The backdrops go with it;
  the original set never had any.
- F9 steps the CRT emulation on a notch, round four settings: CRT OFF, CRT SCANLINES, CRT PHOSPHOR and
  CRT FULL TUBE. Each press adds one thing and the fourth takes the lot away.
- F10 turns the backdrops on and off.
- F12 switches between full-screen and windowed. The game pauses itself afterwards so you don't die while the
  window is still resizing.
